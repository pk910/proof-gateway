A public entry point for EIP-8025 execution proofs. Submitted proofs are verified by the beacon nodes behind the gateway and, when valid, published to the {{.Network}} execution_proof gossip topic. Below are the most recent proofs those nodes verified.

API

Submit proofs

POST {{.BaseURL}}/eth/v1/beacon/execution_proofs

The body is a list of 1–4 SignedExecutionProofEnvelopes, either as JSON (Content-Type: application/json) or SSZ List[SignedExecutionProofEnvelope, 4] (Content-Type: application/octet-stream). Every node verifies the prover signature and the zk proof in-process before propagating it. The answer is 200 once each proof was accepted by at least one node, otherwise 400 with a failure per rejected proof index.

curl -X POST {{.BaseURL}}/eth/v1/beacon/execution_proofs \
  -H 'Content-Type: application/json' \
  -d '[{"message":{"proof_data":"0x…","proof_type":"2","beacon_block_root":"0x…"},
        "validator_index":"1234","signature":"0x…"}]'

Read proofs

GET {{.BaseURL}}/eth/v1/beacon/execution_proofs/{block_id} returns the verified proofs of a recent block (JSON, or SSZ with Accept: application/octet-stream).

GET {{.BaseURL}}/eth/v1/events?topics=execution_proof streams every verified proof as server-sent event.

GET {{.BaseURL}}/api/proofs and GET {{.BaseURL}}/api/submissions list what is shown below as JSON.
